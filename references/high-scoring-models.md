# 已验证高分脚本模型

## 模型 A：功能证明型众筹主片
差异化钩子 → 产品定义 → 个性表达 → 智能守护 → 骑行安全 → 场景扩展 → 可靠性 → 团队/CTA。

适合功能多、需要用户教育、样机可真实演示、用户最大障碍是不理解或不相信的产品。

高分规则：开场先展示普通产品做不到的结果；每个功能遵循“场景→动作→产品响应→结果”；真实实机为主；突出1–3个核心卖点；众筹段补足信任和CTA。

## 模型 B：故事场景型产品主片
人物目标 → 出发仪式 → 日常使用 → 障碍 → 产品帮助判断/解决 → 人物主动继续 → 环境变化触发安全功能 → 抵达与视觉闭环。

适合单演员、生活方式产品、需要品牌感和情绪、功能可由连续事件自然触发的项目。

高分规则：主角有明确可视化目标；障碍轻量可信可拍；产品提供信息/反馈/能力，不神奇解决一切；开头结尾用同一图案、动作或地点闭环；不适合主线的功能留给补充短片。
