# vane-product-video-script

Vane 的产品视频脚本与分镜 Skill，用于商业产品宣传片、Kickstarter 众筹主片、故事型产品广告、功能介绍片、电商和社媒商业短片。

## 核心特点
- 写脚本前先选择用途；
- 支持优秀案例学习；
- 自动整理产品资料；
- 先推荐脚本手法与呈现形式；
- 先确认创意或故事，再拆分镜；
- 支持单演员、自然光、预算与场景约束；
- 按需导出 XLSX；
- 不自动生成分镜画面。

## 建议调用
- 调用 `$vane-product-video-script`。
- 我要给一个新产品写脚本，先选择用途。
- 用故事型产品广告模式处理这个产品。
- 按 Kickstarter 众筹主片流程分析这些资料。
